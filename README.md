# AI-Assisted Resume Portfolio Generator

A simple and robust Python project that takes a resume from `resume.txt` and automatically generates a clean, responsive portfolio webpage (`portfolio.html`) using the Gemini API.

---

## 📋 What the Project Does

The **AI-Assisted Resume Portfolio Generator** simplifies portfolio creation by extracting factual information from a raw text resume and structuring it into a modern, accessible web portfolio.

1. **Reads & Cleans**: Validates and cleans raw resume text from `resume.txt`.
2. **AI Extraction**: Sends the resume to Google's Gemini API with strict anti-hallucination constraints to extract structured JSON data.
3. **Template Assembly**: Populates a semantic HTML template (`template.html`) styled with pure CSS (`style.css`).
4. **Conditional Display**: Displays only sections that actually contain information (omitting empty sections without clutter).
5. **Generates Webpage**: Outputs a standalone `portfolio.html` file ready to publish or view in any browser.

---

* **Python 3.10+** (Standard library: `urllib.request`, `json`, `html`, `os`, `sys`)

## 🔑 How to Add the Gemini API Key

1. Obtain a free Gemini API key from [Google AI Studio](https://aistudio.google.com/).
2. Create a `.env` file in the project root by copying `.env.example`:

```bash
cp .env.example .env
```

3. Open `.env` and set your key:

```env
GEMINI_API_KEY=your_actual_api_key_here
```

Alternatively, set the environment variable directly in your terminal:

```bash
export GEMINI_API_KEY="your_actual_api_key_here"
```

> **Security Note:** Never commit your `.env` file or write your API key directly in Python files. `.env` is listed in `.gitignore` by default.

## 🔄 How `resume.txt` Becomes `portfolio.html`

```text
       resume.txt
           ↓
   [main.py: read_and_clean_resume]
   - Checks file existence, non-emptiness & length
   - Strips redundant whitespaces and blank lines
           ↓
   [main.py: call_gemini_api]
   - Sends strictly instructed prompt to Gemini API
   - Configures responseMimeType: "application/json"
           ↓
   [Gemini API: Structured JSON Output]
   - Strict factual extraction without hallucination
           ↓
   [main.py: parse_and_validate_json]
   - Safely parses and validates JSON schema
           ↓
   [main.py: build_portfolio_html]
   - Escapes HTML entities
   - Conditionally renders non-empty sections
   - Injects into template.html with style.css
           ↓
      portfolio.html
```

## ⚠️ AI Limitations & Hallucination Risks

### Anti-Hallucination Measures
To prevent AI hallucination, `main.py` enforces explicit negative constraints in the system prompt:
- *"Use only information explicitly stated in the resume."*
- *"Do NOT make up, assume, extrapolate, or invent any information."*
- *"Do NOT invent skills, experience, companies, dates, projects, or links."*
- *"Return empty values when information is missing."*
- Temperature is locked at `0.1` to maximize deterministic, factual extraction.

### Known AI Limitations
- **Formatting Variability**: Unconventional ASCII tables or non-standard formatting in `resume.txt` may require clarification.
- **Context Constraints**: The model cannot infer unlisted dates or technologies; if a technology is omitted from `resume.txt`, it will not appear in the generated portfolio.
- **Verification Recommended**: Users should review the generated `portfolio.html` before sharing or deploying.
